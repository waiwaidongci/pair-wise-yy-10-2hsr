# 线材回潮准入与贴线复核台

漆线雕工坊的线材回潮准入、领料占用与贴线进度复核工具。纯静态页面，直接打开 `index.html` 即可使用，数据存于 localStorage。

## 文件划分（三个业务文件）

| 文件 | 职责 |
| --- | --- |
| `rules.js` | 业务规则层：回潮准入、领料冲突、幂等/并发、进度失效与留档。不碰 DOM，不直接读写存储；所有动作返回类 HTTP 结果 `{ ok, status, body, error }` |
| `storage.js` | 存储层：localStorage 原子读写、键命名空间、演示种子（线材批次 + 作品，含一份留档旧版） |
| `app.js` | 页面层：建档、领料、复检、刷新核对的表单交互与看板/留档渲染，仅通过规则服务操作数据 |

## 核心规则

- **回潮准入**：含水率 **> 12%** 或复检日期 **超过 7 天**的批次只能「留检」，领料返回 `422`，不形成领用。
- **单件占用**：同一线材批次贴线未完成前，不得再领给第二件；冲突返回 **`409` 且不写入**。贴线进度到 100% 后批次释放，可再领下一件。
- **更正失效**：胎体、纹样或已领批次任一更正后，当前贴线进度立即清零、作品回到「待复核」；更正前的版本快照存入留档，**旧版不出现在当前队列**，可在留档区/作品详情中查看。更换批次时旧批次同步释放、新批次先做准入与占用校验，不通过则整笔更正不写入。
- **重复 / 并发领用沿用首次结果**：相同请求（`requestId`）在途并发时复用同一个 Promise；完成后首次结果（含 409/422 失败结果）入幂等账，重复提交返回该结果并标记 `replayed`。跨件并发抢同一批次时，同步占位 + 提交时二次校验，保证先到者成功、后来者 409。
- **复检**：对批次登记新含水率（复检日期记为今天），达标转合格可领，不达标继续留检。
- **刷新核对**：重算各批次准入结论、清理失效占用；贴线中作品所用批次转为留检时，作品退回「待复核」并记录原因。页面打开时自动执行一次刷新。

## 页面操作

1. **建档**：填写胎体材质、纹样主题，作品进入「待复核」。
2. **领料**：选择作品与批次做回潮准入；另提供「重复领用」（同请求连续两次，验证沿用首次结果）与「并发演示」（同批同时领给两件，验证 409）两个按钮。
3. **复检**：在批次卡片上登记最新含水率。
4. **刷新核对状态**：顶部按钮（打开页面时也会自动刷新）。
5. 看板支持更新贴线进度（100% 完成释放批次）、待复核件复核恢复、更正并查看留档。
